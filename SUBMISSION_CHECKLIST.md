# OSI Hackathon submission checklist

- [ ] Public repository URL opens without signing in.
- [ ] README explains purpose, data source, setup, run, tests, limitations, and team.
- [ ] Run `python -m unittest discover -s tests -v` successfully.
- [ ] Marimo app launches in a clean environment.
- [ ] Real UCI dataset loads.
- [ ] All three models run and metrics are recorded honestly.
- [ ] Write-up is at most one page and uses results from an actual run.
- [ ] Demo video is four minutes or shorter if included.
- [ ] Public social post link is entered in the form.
- [ ] Repository URL is entered in the form.
- [ ] Event rules reviewed and confirmation checkbox selected.
- [ ] Marimo track selected only if its tools are genuinely used.
- [ ] Valency and Adaption left unchecked unless integrated and used.
