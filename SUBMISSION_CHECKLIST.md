# OSI Hackathon submission checklist

- [ ] Public repository opens without signing in.
- [ ] README explains CrystalCast, its question, dataset, setup, tests, and limitations.
- [ ] Install dependencies in a clean Python environment.
- [ ] Run python -m unittest discover -s tests -v successfully.
- [ ] Launch the Marimo app.
- [ ] Load the actual RWTH Excel dataset and verify target/feature columns.
- [ ] Evaluate all three models using the same test fraction and seed.
- [ ] Record actual MAE, RMSE, R², sample count, test fraction, and seed.
- [ ] Test the user-entered composition prediction and report any unsupported elements clearly.
- [ ] Fill the write-up Results section using actual dataset results.
- [ ] Prepare a demo of four minutes or less if including video.
- [ ] Publish a public social post and paste its URL into the submission form.
- [ ] Paste the public repository URL into the form.
- [ ] Review event rules and confirm the entry follows them.
- [ ] Select the Marimo track only if Marimo tools are genuinely used.
- [ ] Leave Valency and Adaption unchecked unless those tools are integrated and used.
